# 🥦 Online Veggie Mart

A modern and responsive **Online Vegetable Shopping Website** built to provide users with a seamless experience for browsing and purchasing fresh vegetables online.


### 2️⃣ Navigate to Project

```bash

```

### 3️⃣ Run Project

Open `index.html` in your browser.
